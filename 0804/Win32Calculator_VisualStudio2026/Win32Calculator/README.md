# Win32 연속 계산기

Visual Studio 2026과 C++로 만든 순수 Win32 GUI 계산기입니다. Qt, MFC 등 별도 GUI 프로그램이나 외부 라이브러리가 필요하지 않습니다.

## 실행 방법

1. `Win32Calculator.sln`을 Visual Studio 2026에서 엽니다.
2. 상단 구성을 `Release`, 플랫폼을 `x64`로 선택합니다.
3. `Ctrl+Shift+B`로 빌드합니다.
4. `x64\Release\Win32Calculator.exe`를 실행합니다.

Visual Studio 설치 시 **C++를 사용한 데스크톱 개발** 구성요소는 설치되어 있어야 합니다.

## 사용법

- 마우스로 버튼을 누르거나 숫자 키, `+ - * / % .`, Enter 키를 사용할 수 있습니다.
- Backspace: 한 글자 삭제
- Delete: 현재 입력만 지우기(CE)
- Esc: 전체 지우기(C)
- 연속 계산 예: `12 + 3 × 4 =` → `60` (일반 계산기처럼 입력 순서대로 계산)
- 반복 계산 예: `5 + 2 = =` → `9`

## 포함 기능

- 사칙연산과 연속 계산
- 반복 `=` 계산
- 소수점, 부호 변경, 퍼센트
- 제곱, 제곱근, 역수
- CE, C, 백스페이스
- 0으로 나누기 및 잘못된 제곱근 오류 처리
- 창 크기에 맞춘 버튼 자동 배치
