## 4. AI를 활용한 학습 내용

이 저장소에서 AI는 단순히 정답 코드를 받는 용도가 아니라 **설명, 코드 초안 생성, 오류 해결, 코드 분석, 문서 작성**을 돕는 학습 도구로 활용되었습니다.

### 4.1 개념 설명과 학습자료 정리

- 날짜별로 작성한 예제 코드를 바탕으로 핵심 문법과 개념 정리
- 짧은 수업 메모를 구조화된 Markdown 학습자료로 확장
- C/C++ 문법, 객체지향, Win32 메시지 구조와 Qt 동작 방식 설명
- 파일별 역할과 실행 결과를 분석하여 README로 정리
- 복습할 수 있도록 핵심 개념, 주의점과 확인 문제 구성

AI를 이용해 흩어진 코드와 메모를 다시 읽기 쉬운 형태로 정리함으로써, 예제를 실행한 뒤 이론을 복습할 수 있는 학습 기록을 만들었습니다.

### 4.2 코드 초안 생성과 기능 구현

`0804` 폴더의 계산기와 도서관리 프로그램은 필요한 기능과 실행 환경을 AI에 설명하고, 생성된 코드를 바탕으로 제작한 프로젝트입니다.

| AI 활용 대상 | 요청·설계 내용 | 생성 후 직접 확인한 내용 |
|---|---|---|
| Win32 계산기 | 버튼식 계산기, 키보드 입력, 연속 계산, 단항 연산 | 이벤트 처리, 계산 상태, 0 나누기와 입력 오류 |
| Qt 도서관리 | 등록·검색·대출·반납·삭제, JSON 저장 | Qt 위젯, 시그널·슬롯, 데이터 검증과 저장 위치 |
| Win32 도서관리 | Qt와 같은 기능을 순수 Win32 API로 구현 | 메시지 처리, 컨트롤 ID, 바이너리 입출력, 화면 재배치 |

AI가 만든 초안은 최종 결과가 아니라 학습 시작점으로 사용했습니다. 실제 개발 환경에서 빌드하고 동작을 확인하면서 필요한 부분을 수정했습니다.

### 4.3 오류 분석과 코드 수정

AI 생성 코드를 사용할 때 다음 항목을 직접 검증하고 수정하는 방식으로 학습했습니다.

1. Visual Studio 또는 CMake에서 코드 빌드
2. 컴파일 오류와 링커 오류 메시지 확인
3. 여러 파일의 `main()` 함수 중복 여부 확인
4. 필요한 헤더, 라이브러리와 프로젝트 설정 점검
5. 계산·검색·대출·저장 기능을 직접 실행하여 결과 확인
6. 예외 상황과 잘못된 입력 처리 보완
7. 수정 전후 코드와 실행 결과 비교

이 과정을 통해 AI가 생성한 코드를 그대로 복사하는 것이 아니라, **코드를 읽고 오류를 찾아 수정할 수 있는 능력**을 함께 훈련했습니다.

### 4.4 같은 요구사항의 여러 구현 비교

도서관리 프로그램을 Qt와 Win32 API 두 방식으로 구현하여 AI가 같은 요구사항을 서로 다른 기술로 어떻게 표현하는지 비교했습니다.

| 비교 항목 | Qt | Win32 API |
|---|---|---|
| 화면 구성 | 위젯과 레이아웃 | 윈도우 핸들과 좌표 기반 컨트롤 |
| 이벤트 처리 | 시그널·슬롯 | Windows 메시지와 `WndProc` |
| 데이터 저장 | JSON | 바이너리 파일 |
| 빌드 방식 | CMake·Qt 6 | Visual Studio 프로젝트 |
| 학습 효과 | 비교적 간결한 GUI 구조 | 운영체제 수준의 메시지 처리 이해 |

하나의 답만 받는 방식보다 두 구현을 비교하면서 프레임워크가 제공하는 기능과 직접 작성해야 하는 기능의 차이를 확인했습니다.

### 4.5 PRD와 개발 문서 작성

AI를 이용해 PRD의 개념, 목적, 기능·비기능 요구사항, 우선순위와 인수 기준을 정리했습니다. 이를 통해 프로그램을 바로 코딩하기 전에 다음 내용을 먼저 정의하는 방법을 학습했습니다.

- 제품이 해결할 사용자 문제
- 목표 사용자와 사용 환경
- 필수 기능과 제외 범위
- 기능 요구사항과 비기능 요구사항
- 완료 여부를 판단하는 인수 기준
- 일정, 위험 요소와 미정 사항

관련 파일: `0804/PRD_guide.md`

### 4.7 AI 활용 학습 절차

저장소에 나타난 AI 활용 방식을 학습 절차로 정리하면 다음과 같습니다.

1. 만들 프로그램과 필요한 기능을 자연어로 설명한다.
2. AI가 제안한 코드와 구조를 확인한다.
3. 코드의 함수, 클래스와 데이터 흐름을 분석한다.

5. 오류 메시지와 예상하지 못한 동작을 확인한다.
6. AI의 설명을 참고하되 원인을 직접 코드에서 찾는다.
7. 수정한 코드를 다시 실행하고 기능을 검증한다.
8. 배운 내용과 수정 이유를 README에 기록한다.

이 방식은 AI의 빠른 코드 생성 능력과 직접 실행·검증하는 학습을 결합한 형태입니다.
