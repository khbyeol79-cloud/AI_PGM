## 2. C와 C++의 기본 입출력

### 2.1 C 방식: `basic.c`

```c
int a, b, sum;
scanf_s("%d %d", &a, &b);
sum = a + b;
printf("%d", sum);
```

- `scanf_s()`로 값을 입력받는다.
- 입력받을 변수의 **주소**를 전달하므로 변수 앞에 `&`를 붙인다.
- `printf()`의 `%d`는 정수를 출력하는 서식 지정자이다.
- `sum = a + b`는 두 값을 더한 결과를 `sum`에 저장한다.

### 2.2 C++ 방식: `basic.cpp`

```cpp
int a, b, sum;
cin >> a >> b;
sum = a + b;
cout << sum;
```

- `cin`은 표준 입력 객체이다.
- `cout`은 표준 출력 객체이다.
- C++의 `cin`에서는 변수 앞에 `&`를 붙이지 않는다.
- `>>`는 입력 스트림 연산자, `<<`는 출력 스트림 연산자이다.

### 2.3 지역 변수와 전역 변수

```cpp
int g = 20;          // 전역 변수

int add(int x, int y) {  // 전역 함수
    return x + y;
}

int main() {
    int a, b, sum;   // 지역 변수
}
```

- **전역 변수**는 함수 밖에서 선언하며 여러 함수에서 사용할 수 있다.
- **지역 변수**는 함수 또는 블록 안에서 선언하며 해당 범위에서만 사용할 수 있다.
- `add()`처럼 특정 작업을 묶어 놓은 코드를 **함수**라고 한다.
- 현재 예제에서는 `g`와 `add()`가 선언되어 있지만 `main()`에서 사용되지는 않는다.

## 3. 연산자

`pm.cpp`는 C++에서 자주 사용하는 여러 연산자를 한 번에 확인하는 예제이다.

초기값은 다음과 같다.

```cpp
int a = 5, b = 10, c;
```

### 3.1 주요 연산 결과

| 표현식 | 결과 | 핵심 개념 |
|---|---:|---|
| `a + b / 3 * 3` | `14` | 정수 나눗셈과 연산자 우선순위 |
| `b << 2` | `40` | 비트를 왼쪽으로 두 칸 이동 |
| `a != b` | `1` | 두 값이 다르므로 참 |
| `b % a` | `0` | 나머지 연산 |
| `(a > b) ? a : b` | `10` | 두 값 중 큰 값을 선택하는 삼항 연산자 |
| `sizeof(a)` | 일반적으로 `4` | 자료형 또는 변수의 메모리 크기 |
| `c = a++` | `5` | 먼저 대입한 후 `a`가 1 증가 |
| `a += b` | `16` | `a = a + b`와 같은 의미 |
| `a & b` | `0` | 정수의 각 비트에 AND 연산 수행 |
| `c = (a + b, a - b)` | `6` | 쉼표 연산자의 마지막 식이 결과가 됨 |

### 3.2 정수 나눗셈

```cpp
10 / 3    // 결과: 3
```

두 피연산자가 모두 정수이면 소수점 아래는 버려진다. 실수 결과가 필요하면 한쪽 값을 실수로 만들어야 한다.

```cpp
10.0 / 3  // 결과: 약 3.33333
```

### 3.3 후위 증가 연산자

```cpp
c = a++;
```

실행 순서는 다음과 같다.

1. 증가 전의 `a` 값을 `c`에 저장한다.
2. 그 후 `a`를 1 증가시킨다.

예를 들어 `a`가 5였다면 `c`는 5, `a`는 6이 된다.

### 3.4 비트 이동과 비트 AND

```cpp
b << 2
```

양수의 비트를 왼쪽으로 한 칸 이동할 때마다 값이 일반적으로 2배가 된다. 따라서 `10 << 2`는 `10 × 2² = 40`이다.

```cpp
a & b
```

`&`는 두 정수의 같은 위치에 있는 비트가 모두 1일 때만 결과 비트를 1로 만든다. 논리 AND인 `&&`와 구분해야 한다.

## 4. `for` 반복문과 누적 합계

`for.cpp`는 두 정수 사이의 모든 정수를 더하는 예제이다.

```cpp
int i, a, b, sum = 0;
cin >> a >> b;

for (i = a; i <= b; i++) {
    sum += i;
}
```

### 4.1 `for`문의 구조

```cpp
for (초기식; 조건식; 증감식) {
    반복할 코드;
}
```

- 초기식 `i = a`: 반복을 시작할 값을 정한다.
- 조건식 `i <= b`: 이 조건이 참인 동안 반복한다.
- 증감식 `i++`: 한 번 반복할 때마다 `i`를 1 증가시킨다.
- `sum += i`: 현재 `i` 값을 기존 합계에 누적한다.

예를 들어 `a = 1`, `b = 5`이면 `1 + 2 + 3 + 4 + 5 = 15`가 된다.

### 4.2 주의할 점

현재 코드는 첫 번째 입력값이 두 번째 입력값보다 큰 경우 반복문이 한 번도 실행되지 않는다. 어느 순서로 입력해도 계산하려면 두 값의 크기를 비교한 뒤 교환하는 처리가 필요하다.

## 5. C 스타일 문자열과 `while`문

`ConsoleApplication1.cpp`는 한 줄의 문자열을 입력받아 전체 글자 수와 영문 소문자 `e`의 개수를 센다.

```cpp
char line[100];
cin.getline(line, 100, '\n');
```

- `char line[100]`은 문자 100개를 저장할 수 있는 문자 배열이다.
- `cin.getline()`은 공백을 포함한 한 줄을 입력받는다.
- 최대 99개의 실제 문자와 문자열 끝을 나타내는 널 문자 `\0`을 저장할 수 있다.

### 5.1 문자열 끝 확인

```cpp
int count = 0;
int i = 0;

while (line[i] != '\0') {
    if (line[i] == 'e')
        count++;
    i++;
}
```

- C 스타일 문자열은 마지막에 `\0`이 들어간다.
- `while`문은 `\0`을 만날 때까지 문자를 하나씩 검사한다.
- `i`는 현재 문자의 위치인 동시에 최종적으로 전체 글자 수가 된다.
- 문자가 `e`와 같을 때마다 `count`를 1 증가시킨다.
- 대문자 `E`는 세지 않는다.

## 6. `std::string` 배열

### 6.1 문자열 배열 초기화: `string.cpp`

```cpp
string a[3] = { "12345", "abcd", "qwer" };

for (int i = 0; i < 3; i++) {
    cout << a[i] << endl;
}
```

- `string a[3]`은 문자열 세 개를 저장하는 배열이다.
- 배열 인덱스는 `0`부터 시작하므로 `a[0]`, `a[1]`, `a[2]`를 사용한다.
- `i < 3`으로 설정해야 배열 범위를 벗어나지 않는다.
- `endl`은 줄을 바꾼다.

### 6.2 관련 데이터를 같은 인덱스로 관리: `string1.cpp`

```cpp
string stdname[3];
int stdnum[3];
```

학생 이름과 번호를 각각의 배열에 저장하고, 같은 인덱스를 이용해 하나의 학생 정보처럼 연결한다.

```cpp
stdname[0]  // 첫 번째 학생 이름
stdnum[0]   // 첫 번째 학생 번호
```

첫 번째 `for`문은 세 명의 정보를 입력받고, 두 번째 `for`문은 저장된 정보를 출력한다. 이후 구조체나 클래스를 배우면 이름과 번호를 하나의 자료형으로 묶는 편이 더 안전하고 편리하다.

## 7. 클래스와 객체

`ConsoleApplication2.cpp`는 원의 반지름과 넓이 계산 기능을 하나의 클래스로 묶은 예제이다.

```cpp
class circle {
public:
    int radius;
    double getArea();
};
```

- **클래스**는 데이터와 기능을 묶어 만든 사용자 정의 자료형이다.
- `radius`는 클래스가 가지는 **멤버 변수**이다.
- `getArea()`는 클래스가 수행하는 **멤버 함수**이다.
- `public`으로 선언된 멤버는 클래스 외부에서도 접근할 수 있다.

### 7.1 클래스 외부에서 멤버 함수 구현

```cpp
double circle::getArea() {
    return 3.14 * radius * radius;
}
```

`circle::getArea()`의 `::`는 **범위 지정 연산자**이다. 이 함수가 `circle` 클래스에 속한다는 뜻이다.

### 7.2 객체 생성과 사용

```cpp
circle donut;
donut.radius = 1;
double area = donut.getArea();
```

- `donut`은 `circle` 클래스로 만든 **객체**이다.
- `.` 연산자를 이용해 객체의 멤버에 접근한다.
- 같은 클래스로 `donut`, `pizza`처럼 서로 다른 상태를 가진 여러 객체를 만들 수 있다.

## 8. 생성자와 생성자 오버로딩

`test.cpp`와 `test1.cpp`는 사각형 클래스를 통해 생성자 사용법을 연습한다.

```cpp
class Rectangle {
public:
    int width, height;

    Rectangle();
    Rectangle(int w, int h);
    Rectangle(int length);
    bool isSquare();
};
```

### 8.1 생성자의 특징

- 생성자의 이름은 클래스 이름과 같다.
- 반환 자료형을 작성하지 않는다.
- 객체가 만들어질 때 자동으로 호출된다.
- 매개변수 구성을 다르게 하여 여러 생성자를 만들 수 있다. 이를 **생성자 오버로딩**이라고 한다.

### 8.2 생성자별 동작

```cpp
Rectangle::Rectangle() {
    width = height = 1;
}
```

매개변수가 없는 기본 생성자이다. 가로와 세로를 모두 1로 만든다.

```cpp
Rectangle::Rectangle(int w, int h) {
    width = w;
    height = h;
}
```

가로와 세로를 각각 전달받는다.

```cpp
Rectangle::Rectangle(int length) {
    width = height = length;
}
```

한 변의 길이만 받아 정사각형을 만든다.

### 8.3 생성자 호출 구분

| 객체 생성 코드 | 호출되는 생성자 | 결과 |
|---|---|---|
| `Rectangle rect1;` | `Rectangle()` | `1 × 1` 정사각형 |
| `Rectangle rect2(3, 5);` | `Rectangle(int, int)` | `3 × 5` 직사각형 |
| `Rectangle rect3(3);` | `Rectangle(int)` | `3 × 3` 정사각형 |

### 8.4 `bool` 반환 함수

```cpp
bool Rectangle::isSquare() {
    if (width == height) return true;
    else return false;
}
```

가로와 세로가 같으면 `true`, 다르면 `false`를 반환한다. 다음처럼 더 간단히 작성할 수도 있다.

```cpp
bool Rectangle::isSquare() {
    return width == height;
}
```

## 9. `private`와 `public`

`test2.cpp`는 클래스의 접근 지정자에 따라 어떤 코드가 허용되는지 확인하는 예제이다.

```cpp
class PrivateAccessError {
private:
    int a;
    void f();
    PrivateAccessError();

public:
    int b;
    PrivateAccessError(int x);
    void g();
};
```

### 9.1 접근 가능 범위

| 멤버 | 지정자 | 클래스 내부 | 클래스 외부의 `main()` |
|---|---|---:|---:|
| `a` | `private` | 가능 | 불가능 |
| `f()` | `private` | 가능 | 불가능 |
| 기본 생성자 | `private` | 가능 | 불가능 |
| `b` | `public` | 가능 | 가능 |
| 매개변수 생성자 | `public` | 가능 | 가능 |
| `g()` | `public` | 가능 | 가능 |

따라서 다음 코드는 외부에서 실행할 수 없다.

```cpp
// PrivateAccessError objA; // private 기본 생성자 호출
// objB.a = 10;            // private 변수 접근
// objB.f();               // private 함수 호출
```

반면 다음 코드는 `public` 멤버를 사용하므로 실행할 수 있다.

```cpp
PrivateAccessError objB(100);
objB.b = 20;
objB.g();
```

`private`는 객체의 내부 데이터를 외부에서 직접 변경하지 못하게 보호한다. 이것이 객체지향 프로그래밍의 **정보 은닉**과 **캡슐화**의 기초이다.

## 10. 코드 작성 시 보완하면 좋은 부분

### 10.1 `std::string` 헤더 명시

`string`을 사용할 때는 다음 헤더를 직접 포함하는 것이 올바르다.

```cpp
#include <iostream>
#include <string>
```

일부 컴파일러에서는 `<iostream>`을 포함하는 것만으로도 동작할 수 있지만, `<string>`을 명시해야 코드의 의존 관계가 분명해진다.

### 10.2 클래스 이름 표기

C++에서는 클래스 이름을 대문자로 시작하는 관례를 많이 사용한다.

```cpp
class Circle {
    // ...
};
```

이는 문법상의 필수 사항은 아니지만 변수와 클래스 이름을 쉽게 구분할 수 있다.

### 10.3 원주율 표현

`3.14`는 간단한 학습 예제에는 적합하지만 정밀한 계산에는 더 정확한 값을 사용할 수 있다.

```cpp
#include <numbers>

return std::numbers::pi * radius * radius; // C++20
```

### 10.4 멤버 변수 보호

원의 `radius`나 사각형의 `width`, `height`를 `private`로 선언하면 외부에서 잘못된 값을 직접 저장하는 것을 제한할 수 있다.

### 10.5 파일별 `main()` 함수

각 예제에는 독립적인 `main()` 함수가 있다. 여러 예제 파일을 하나의 프로젝트에서 동시에 빌드 대상으로 추가하면 `main()`이 여러 개라는 링커 오류가 발생한다. 한 번에 학습할 파일 하나만 빌드 대상으로 사용하거나 예제마다 프로젝트를 분리해야 한다.

### 10.6 저장소 정리

폴더에는 원본 학습 파일과 프로젝트 내부 복사본이 함께 있어 같은 코드가 중복되어 있다. 또한 `x64/Debug` 아래의 `.obj`, `.pdb`, `.ilk`, `.exe` 등은 빌드할 때 다시 생성되는 파일이다. 일반적으로 Git 저장소에는 소스와 프로젝트 설정만 남기고 빌드 결과물은 `.gitignore`로 제외한다.
